# baby

MVP d'une app iOS et Android avec widget : quand sortir avec bébé, comment l'habiller, et ce qu'il lui faudra bientôt. Toute information de santé relaie une source officielle citée ; l'app ne donne pas d'avis médical.

- `rules/` : règles v0 en JSON et charte des sources (voir `rules/README.md`)
- `tools/` : moteur de référence et tests, `node tools/run-vectors.mjs` (Node 18+)

Statut : règles v0 en brouillon, apps natives pas encore commencées.
