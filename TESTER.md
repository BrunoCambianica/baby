# Tester Superbébé (version 0.1)

Merci de tester ! Pendant deux à trois semaines, regardez l'app avant de sortir avec bébé, et le soir avant le coucher.

## 1. Installer l'app (2 minutes)

- **iPhone** : ouvrez <https://brunocambianica.github.io/baby/> dans **Safari**, bouton Partager, puis « Sur l'écran d'accueil ».
- **Android** : ouvrez le même lien dans **Chrome**, menu ⋮, puis « Installer l'application ».

Au premier lancement : votre commune, le mois de naissance de bébé, et comment vous sortez le plus souvent (poussette, porte-bébé ou voiture).

## 2. Ajouter le widget sur iPhone (5 minutes)

C'est le cœur du test : la réponse s'affiche sans ouvrir l'app, même sur l'écran verrouillé.

1. Installez **Scriptable** (gratuit) depuis l'App Store.
2. Dans Superbébé : « Widget et installation », puis **Copier le script**.
3. Dans Scriptable : touchez **+**, collez, nommez le script « Superbébé », puis touchez ▶ une fois.
4. Revenez dans Superbébé : **Copier ma configuration**.
5. Ajoutez un widget Scriptable :
   - écran d'accueil : appui long, **+**, Scriptable, taille moyenne ;
   - ou écran verrouillé : appui long, Personnaliser, puis un widget Scriptable rectangulaire.
6. Touchez le widget pendant la modification : Script = **Superbébé**, Paramètre = collez la configuration.

Toucher ensuite le widget ouvre un petit menu pour noter la température de la chambre ou dire si la tenue allait.

## 3. Ce qu'on vous demande

- Après une sortie, dites si la tenue allait : **trop chaud**, **bien** ou **trop froid**. Les tenues suivantes s'ajustent.
- Le soir, notez la température de la chambre avec les boutons − et +.
- Dans « À prévoir », indiquez ce que vous avez déjà.
- À la fin du test, ouvrez Réglages, touchez **Copier mes retours de test**, collez-les dans notre conversation et répondez à trois questions :
  1. Si l'app disparaissait demain, ce serait : très embêtant, un peu embêtant, ou pas grave ?
  2. Qu'est-ce qui vous a été le plus utile ?
  3. Qu'est-ce qui manque, ou vous a agacé ?

## Bon à savoir

- **Ce n'est pas un avis médical.** Les repères de santé viennent de sources publiques (Santé publique France, ministère de la Santé, Météo-France…), citées dans l'app. En cas de doute sur la santé de bébé, appelez votre médecin. Urgence : 15 ou 112.
- **Vos données restent sur votre téléphone** : pas de compte, pas de publicité, pas de mesure d'audience.
- **Version de test** : la vigilance Météo-France et les épisodes de pollution ne sont pas encore intégrés ; le widget Android natif arrive ensuite.
