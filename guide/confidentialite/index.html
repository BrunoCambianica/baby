Confidentialité

Pas de compte, pas de publicité, pas de mesure d'audience. Le profil de votre enfant reste sur votre téléphone.

Ce qui reste sur votre téléphone

Le mois de naissance de l'enfant et, si vous le voulez, son prénom ou un surnom ; la commune, les réglages, la garde-robe, les températures notées et vos réponses « il avait trop chaud, juste, trop froid ».

Ce qui en part, et pourquoi

  • La météo : la position de la commune est envoyée à Open-Meteo, pour les prévisions heure par heure et les températures des années passées.
  • La commune : le nom tapé, ou votre position arrondie à environ 1 km si vous la demandez, est envoyé à geo.api.gouv.fr, un service public, pour trouver la commune.
  • Le partage avec l'autre parent : un lien à envoyer par message, avec les prénoms et les réglages. Il ne passe par aucun serveur de Superbébé.
  • La fiche du jour pour la nounou ou la crèche : une image et un lien, avec le prénom seulement, ni nom de famille ni adresse. Les données sont dans le lien, après le « # », que le navigateur n'envoie pas au serveur.
  • Les retours de test : un résumé sans prénom (âges, modes de sortie, réponses), que vous envoyez vous-même si vous le voulez.

Le rappel du soir est calculé sur le téléphone, par l'app Android ou par le widget iPhone.

Hébergement

Le site, l'app et le guide sont servis par GitHub Pages : GitHub peut traiter des données techniques de connexion, comme l'adresse IP, selon sa propre politique de confidentialité. Les pages du guide n'ont ni script ni cookie.

Effacer vos données

Dans l'app : Réglages, « Effacer toutes mes données ». Désinstaller l'app, ou effacer les données du site dans le navigateur, fait de même.
